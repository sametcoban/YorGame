# Heroes and skills

Prototype balancing values; all heroes and effects are original. Hero rarity scales health, basic attack, skill damage, healing, and guard: Common ×1, Uncommon ×1.10, Rare ×1.25, Epic ×1.45, Legendary ×1.70 (rounded). Timed defense windows and number of equipped skills do not change with rarity.

## Six skills per class

Equip exactly two distinct skills per hero, between battles. Each equipped skill has two uses per encounter. Basic attacks do not consume skill uses. Guard absorbs damage from the next landed hit on that hero; it survives a successful dodge/parry and does not stack beyond the stronger guard. Party healing affects living allies only. All damage is single target in the current one-enemy prototype.

Explicit skill elements override hero affinity. Other skills inherit the hero affinity. Poison currently means elemental damage, without damage over time. Healing and guard are not modified by enemy resistance.
